# 4.5.4 账单查询与展示

查询读取同一SQLite副本。金额筛选使用精确十进制比较，业务ID保持文本；JSON数值ID的索引使用SQLite的JSON原文字面量，不先经过JavaScript Number或SQL浮点转换。时间、账本、成员、分类、类型与pack有持久索引，标签按账单扩展中的实际ID匹配，备注关键词按字面量处理，百分号/下划线不作为通配符。

筛选可组合账本、隐藏账本、日期、类型、金额上下限、分类及子分类、成员、标签any/all、是否有标签、任一关联资产、备注、来源平台/文字和图片存在状态。默认不包含已知隐藏账本；明确包含隐藏账本时保留它们。未知账单类型保留并标识，不能改成普通收支或直接丢弃。

## 日期和账本来源

实际`Book`序列化ID字段为bookid，visible=1为可见。账本资料来自登录和client/init等独立在线源，保存在books域；不是syncv2下发内容。登录/检查的最新账本对象可以确认对应实体，但不把未证实的列表缺席解释为删除。账单增量不重复回放登录快照，全量重建账单也不清除这个独立来源。

`BookConfig.range`的m25表示每月25日开始。`BookFilter.getBookRangeConfig`在选中账本的range一致时沿用配置，不一致时返回null；查询依同一规则处理月范围。自然日和显式起止日期不受月起日影响。月底29–31的配置仍由任务18补核，当前明确拒绝，不能自行夹到月末。

`CalendarHubPresenterImpl.p`向getBillListOfMonth传null BookConfig；因此日历采用自然月份，而不是把自定义统计周期搬到日历网格。分日使用请求时区，原始秒时间不改变。

## 分页

游标绑定UID、逻辑连接代次、活动数据集、账单/账本修订、规范化筛选及实际时间范围、时区和页长。排序使用业务时间与无损整数ID文本键；同一数据修订内按keyset继续。删账单、改筛选、账本配置/可见性改变、切换数据集或账号后返回PAGE_CHANGED，要求第一页重查。无变化的上游检查不无故使游标失效。

金额范围在有界索引候选上执行精确比较，每次最多扫描5000候选；达到扫描边界仍可继续时返回nextCursor和scan-limit，空的中间页不代表最终没有结果。日历每次最多读取25个200条页面，未结束时返回可继续的游标和complete=false。调用者必须处理nextCursor，不能把截断结果说成完整集合。

## 关系与报销显示

退款、报销与源记录按真实业务ID补载，不添加主列表日期范围，所以一月源记录可加载二月退款。缺失关联和补载上限明确标为不完整，不能按零金额统计。非空rfds优先于旧refundid/refundv，源ID的-1/0哨兵不生成虚假的关系。旧报销字段保留为明确的兼容资料，统计转换由下一任务共用实现。

依据`Lpe/b.b`，仅相邻、type21且packid相同的记录形成显示组。返回的items仍是原始真实账单，rows中的虚拟组仅含displayType22、packId和真实memberIds；单成员展示普通记录。分页边界上的多成员片段带continuedBefore/After。不会保存显示type22、生成billid0或把显示组再次计入原始账单数量。真实下发type22按待核验类型保留。

公开账单DTO列出金额、身份引用、分类、资产、标签、附件、来源、历史币种和关系信息，不包含内部raw请求/响应对象。CurrencyExtra的实际wire字段为ss/sv、ts/tv、bs/bv，映射到明确的历史源/目标/本位值，供统一统计和写入规则复用。
