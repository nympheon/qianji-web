# 周期任务（钱迹 4.5.4 / 1234）

## 上游接口

| 操作 | 原生参数 | 回执 |
| --- | --- | --- |
| `repeat_task/list` | `uid/page/flts`，页从 0 开始，`flts.sort="类型,升序标志"` | `data.list/hasmore` |
| `repeat_task/submit` | `uid/v`，完整 Gson 任务 | `data.task` 和可选 `data.bills` |
| `repeat_task/toggle` | `uid/did` | `data.list` 中的官方账单；状态需另外核对 |
| `repeat_task/bindbill` | `uid/repeatTaskId/billId` | 业务确认 |
| `repeat_task/delete` | `uid/did` | 业务确认 |
| `repeat_task/holidays` | `uid/years`，逗号分隔年份 | `data.years[年份][YYYY-MM-DD]`，含 `holiday` |

排序类型：创建时间 0、状态 1、次数 2、账单类型 3；升序标志为 1，降序为 0。启停仅支持状态 0（暂停）和 1（执行中）；-1/-2/-3 分别表示完成、过期和异常。`resetcount` 的存在未证明活跃产品入口，未注册该动作。

任务管理 ID 为 `id`，实际账单分组为 `packid`。`Bill.importPackId` 的序列化字段也为 `packid`。绑定接口翻转已有关系，不能作为创建账单或自动重试接口。

## 规则与预览

- `RepeatConfig` 使用 `type/value`，支持 day/week/month/year/workday/bystep。每周值为周一 1 至周日 7，年度值为 `月-日`，间隔按日历天增加。
- 月度 32 表示月末，291 表示 29 或月末，301 表示 30 或月末；普通 29/30/31 跳过没有该日的月份。
- 原生首次预览：day/bystep 包含开始日期；month 在开始日期当日符合规则时包含；week/year/workday 查找严格晚于开始日期的下一次。
- `zf/b.o()` 在日期 `>=end.date` 时结束，因此结束日期不含当天；计数结束最多生成指定数量的预览。最多 120 条，均为临时展示对象，没有 Bill ID。
- 工作日使用官方年度映射：明确例外优先，已存在非空年映射时其余日期按周末判断。缺少或空年映射明确提示不可预览。
- 默认预览时区 Asia/Shanghai。不存在或出现两次的本地时间明确报错；未将预览时区作为未经证明的上游参数发送。

**有意修正的 APK 预览问题：**`zf/b.m()` 分别计算最小月份与最小日号，会把 3-30 和 4-1 组合成未选中的 3-1。本服务预览保持月日配对并按日期选择下一项；上送的原生规则不变，正式账单始终使用官方回执。跨闰年等实际执行由专用资源继续核对。

## 写入和一致性

公开输入为结构化字段。新增和部分编辑共用字段校验；编辑保留完整原始任务及未知字段，配置版本忽略执行次数、状态和执行时间变化。部分编辑 schema 不展开创建默认值，网页只提交实际变更。改变金额、费用、资产、币种或类型时才校验新的财务配置，备注编辑保留原有币种数据。

普通支出仅支持负数优惠，收入不支持费用；转账/还款使用同一精确金额和费用计算，历史目标币种金额随已确认规则规范化。图片使用已确认上传引用。任务和启停返回的官方账单先核对账号、分组、账本、类型及重复 ID，再整体应用；预览不会进入账单存储或上传链路。

暂停/恢复发送前读取最新状态，目标已达到时完成原操作而不翻转。绑定先核对任务分组并同步账单；解绑任务 T 时，账单已关联 U 也视为目标达成。结果未知只读核对，禁止再次调用翻转接口。启停和编辑的未知结果还需同步可能产生的账单，新建未知结果不能按相同金额或备注认领另一个任务。

完整官方列表可清理已不存在的任务元数据，保留本地历史账单；其他排序查询随目录变化失效。空列表也按来源校验时间缓存 60 秒。匹配目标的无操作请求保留刚校验的缓存。可能产生账单的周期提交、启停意图纳入账号余额校准前的未同步保护。

官方节假日按实际需要逐年读取并缓存。实际只读检查发现，提前附带下一年度会触发业务拒绝；改为需要跨年时才获取后，2026 工作日预览通过。单次预览最多读取 3 个年度，缺少数据时不推算后续日期。

证据：`network/api/repeattask/a,b,c`、`network/api/bill/f`、`SortFilter.getValue`、`RepeatTaskSubmitAct.A0/h1/E1` 及 k/n 回调、`zf/b.g/h/k/l/m/n/o/buildPreviewBills`、`zf/a`、`rf/c` 绑定回调、`Bill.importPackId` 注解。另见[周期域静态审查](../../research/2026-10-18-apk-scheduled-plans-audit.md)。
