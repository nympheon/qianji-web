# 数据新鲜度与恢复

业务副本保留在SQLite中。60秒是使用时检查上游的间隔；读取不续期，到期不删数据，也不建立每分钟任务。手动增量绕过60秒普通间隔，仍保留APK的5秒完成冷却；不清成功游标。查询并发请求共享同一源任务，进度读取不启动另一轮同步。

源校验时间、数据修订与源写入代次分别保存。重复无变化页只推进完整校验时间；数据修订用于分页和本地派生计算。单条官方回执更新对应实体，不能替整个列表延长校验时间。明确可发送的业务操作在发送标记同一事务中推进`affectedDomains`的源代次，晚到读取不能覆盖后来确认的写入。

在线资料的源元数据按UID、域与规范化查询键保存，成员关系只保存资源ID、类型和顺序。列表、详情与选择器查询同一实体行。完整空结果可缓存；未载入、未完整和已失效范围不能冒充完整空集合。空的过滤列表只替换自己的成员，不删除其他查询的实体；明确删除回执必须指定资源类型。`publishSnapshot`仅用于已核对完整覆盖契约的官方集合。

读取开始时捕获UID、逻辑连接代次、活动数据集和源代次。任一变化后，旧响应返回`superseded`，保留当前资料及其必要失效状态。结果不明的操作与影响域有持久关联；显示读取不能清除此状态，即使读取刚成功，相关完整性仍受待核查操作约束。完整回执优先局部落库，不固定追加全域拉取。

## 全量重建

重建意图先落库并安排唯一alarm，即使仍在等待已有远端写入，已有真实任务ID和waiting阶段。取得持久写入边界后，各选中域使用独立临时数据集及空的本轮起始游标。边界跨请求、对象销毁和alarm续跑保留，查询旧副本与保存草稿不等待网络。

重建期间的写入只排队。所有选中域及其必要源完整后，同库事务发布活动指针及成功游标、解除边界并唤醒排队操作；任一源失败保留原活动集合与成功游标。只重建标签不切账单。标签重建分别读取tag/syncall和完整tag/list分组源。被重建接管的普通增量响应不再落库。

排队操作按SQLite接受顺序执行，UUID字典序不决定同毫秒内的顺序。每次唤醒处理有限任务，已挂起的相关目标不阻塞无关写入。只读结果核查不占远端写入的顺序门，因此可使用重建完成核查，不形成互相等待；核查客户端仍禁止写请求。原始发送尚在进行时，核查返回其真实在途状态。

源页每次最多处理两页，账单200次/标签40页上限跨续跑保留；协调器每次最多取五个到期任务、每次队列推进最多五项。源失败或有限结果核查仍不明确时停止自动请求，等待下次使用。没有在途任务时不安排后台请求。

退出、确认失效或更换UID会停止相应源任务、解除旧边界并清理唤醒；旧响应不能重新启用任务。离线时排队写入保留，连接恢复后重新校验，未发送操作的结果核查不会误取消其任务。副本、草稿与操作记录保留。

只保留活动和仍被在途任务使用的数据集。成功发布或失败停止后，清理无用的暂存/替换集合及其查询成员；不累计整库历史副本，草稿、写键和逐项结果不属于此清理范围。数据库恢复与业务数据导出是不同功能，维护恢复文档在部署阶段补齐。

本地测试已经覆盖真实workerd SQLite、对象销毁后的实际alarm续跑、等待/首中末页写入、跨域失败、迟到读、空结果、时钟与不重发边界；真实钱迹账号及Cloudflare出口的验收仍需实际连接后完成。
