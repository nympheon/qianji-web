- 本位币修改、全局排序与账本成员操作按用户要求不提供；必要的本位币、角色数据只读。没有应用账号系统、导出或产品运维后台。
- 普通/外币收支、转账/信用卡还款、退款和组合报销、借入借出及本金利息、资产资料和差额、账本/分类/标签及关联删除已实际验证。退款最多25条；旧版baoxiaoed报销写入、退款移除既有资产/清空既有图片或标签，保留具体不可用原因。标签权益变化没有通过修改真实账号权益来测试。
- 周期六种规则与五种账单类型配置、日期/次数、启停、财务编辑、绑定及删除已验证。金额按资产币种填写；原生接口不保存预设汇率快照，有此字段的财务变更发送前拒绝，历史原始字段只读保留。随机/resetCount等没有已确认入口的操作不提供。
- 分期18种尾差/费用组合、历史初始执行次数、图片/标签/标记、两项统计配置、绑定、外币提前还款及删除已验证。提前还款images必须为数组，两种账单均核对图片；源扣款总额等于本金加手续费。历史起点测试官方未返回生成账单，因此服务不补造。
- 七种存钱模式配置、纯进度及双向跨币种关联存入、图片/标签、撤销、保留/删除关联账单已验证。该接口忽略手续费，非零手续费发送前拒绝。已有交易改币种、改变计划模式、清空既有图标仍拒绝；无交易币种与同模式规则编辑支持。
